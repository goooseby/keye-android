BEFORE YOU START

开始之前，几个小问题。

已经安装了“课页”，需要重新导入资料吗？

不需要。桌面端已更名为华工课栈，可以通过原有更新入口或运行新安装包覆盖升级。资料库、原始页面、裁剪和整理记录继续沿用，无需先卸载。

校外访问受限，或登录提示 HTTP 403 怎么办？

获取学校内容需要平台可访问，部分校外网络可能受限。请检查校园网或学校 SSLVPN、代理配置，并在同一网络的浏览器中验证。本地资料整理和导出不依赖学校连接。

获取的是原始 PPT 文件吗？

获取的是学校平台记录的投影片页面，可以整理后导出 PDF，不提供原始 PPT / PPTX 或幻灯片动画。可获取内容以本人账号权限和平台实际记录为准。

可以和手机端自动同步吗？

目前 Windows 与 Android 各自维护本地资料，不提供跨设备自动同步。可以把整理后的 PDF 带到其他设备阅读。

在哪里下载？支持什么系统？

支持 Windows 10 / 11 的 64 位系统。推荐直接从本站服务器下载，也可选择 GitHub 下载同一版本安装包并按向导安装。下载文件名保留 Keye，用于兼容旧版更新。
