# 课表与直接阅读

## 产品路径

课页提供两条找课路径：按日期和上课时间定位某一次课，直接打开；按课程保存、批量获取并长期阅读。两条路径复用同一课次、同一本地课件和同一阅读进度，不建立第二套资料库。

底部导航为“课表 / 课程 / 我的”，默认打开课表。课程保留最近阅读、全部课程和离线资料；课表的“批量获取”和课程首页的“获取课件”打开日期查询与多选下载，下载管理从顶栏和我的进入。周次、日期与批量查询的结果分别保存，互不覆盖。

## 手机课表

默认展示整周课表，可点“当日课表”或日期切换到日视图。顶部提供上一周、日期范围、下一周和今天；点日期范围打开日历，可直接跳到历史日期。日期条显示周一至周日、今天及有课提示。下方显示当日课程的时间、名称、教师、教室、学校状态与本地保存状态，省去整天空白时间。

整周以七列紧凑时间格展示分布，同一课程使用稳定的浅色底和细色边，名称与状态分层排版；点课程直接打开，点日期查看当天详情。七列只承担观察分布；完整名称与精确操作由当日视图承担。同日重叠时合成带数量的课程块，点开选择，不让窄小按钮互相遮盖。无明确时段的课次列在“时间待确认”，不猜测位置。学校日期、周界限与显示时间统一按 Asia/Shanghai 解释。

“上周二的机器学习”的路径是：课表 → 上一周 → 周二 → 机器学习 → 阅读。使用本机资料不强制先联网或先整理。

## 加载与长期保存

课表来自学校真实的 `/courseapi/v2/schedule/get-week-schedules`，每次读取完整的周一至周日；展示课表不会逐门获取图片目录，也不自动下载整周课件。

- 登录恢复时提前准备本周。进入页面先显示内存或本机保存的课表，需要时后台更新；已有内容不因刷新清空。
- 本周就绪后准备前后一周。用户向历史浏览时优先准备更早的两周，并兼顾后一周；向未来浏览时反向处理。只准备少量邻周，不下载整个学期。
- 同一账号同一周的并发请求合并，课表请求最多同时两个。快速切周保留有用的在途结果供缓存使用，但旧结果不能覆盖新选择；切到后台停止发起预取。
- 本周在课表或课程首页前台可见时约每分钟更新。历史周一天内复用，未来周六小时内复用；主动刷新可立即重查。有效期只决定是否更新，不决定是否删除。
- 所有已读取周长期保存到 SQLite，不按周数或登录有效期删除。重启仍可读取；账号按租户及用户标识的摘要分区，切换账号不混用课表。缓存不保存密码、Cookie、Token 或图片鉴权地址。

缓存记录更新时间，用于刷新和直播状态判断；页面不常驻显示课程总数、更新时间或操作说明。登录失效后显示紧凑的登录提示，仍可切换已保存周并阅读已下载课件。未保存周明确显示“本周尚未保存”，不误称没有课程。断网时保留内容、说明无法更新，允许重试；只有学校明确拒绝登录才标为登录失效。尚未下载的课件需要重新登录后获取。

## 学校状态与直播

官网使用课程对象的 `status`，不能只依靠上课时间推断直播，也不能把 `is_live` 当作正在直播的布尔开关。

| status | 含义 | 点按行为 |
| --- | --- | --- |
| 1 | 直播中 | 有效登录和新鲜状态下直接进入跟看 |
| 2 | 未开始 | 已保存课件可读；没有本地页时先展示课次信息，可主动检查预上传课件 |
| 3 | 回放生成中 | 独立查询 PPT，有页面就能阅读 |
| 5 | 暂无回放 | 不据此判定没有 PPT，仍可检查课件 |
| 6 | 回放 | 打开本机课件，或获取后阅读 |
| 缺失／其他 | 状态未知 | 保守显示，不冒充直播 |

数字和数字字符串均兼容，保留原始状态及服务端标签；空标签使用已确认的代码映射。视频状态与本地“已存 X 页 / 待补全 / 正在获取”分别表达。可见性遵循官网对 sub_review_type 的规则及管理员例外，入口不能绕过学校权限。

课表及课程首页的紧凑直播入口使用三条竖条标识，不伪装真实音频。只有有效登录、本次已联网确认、数据未过期且服务器确认直播时出现；多个直播可分别进入，没有直播不保留空卡片。系统关闭动画或应用后台时静态显示。缓存或联网失败时去掉实时确定性提示，不宣布课程已经下课，也不强行关闭用户正在看的内容。跟看图片约三秒的轮询与课表状态刷新相互独立。

## 直接阅读与下载的衔接

课次沿用稳定的 sourceKey 身份，与课程、本地文件、阅读位置及批注对应，不以名称加日期猜测合并。

已有本地页面立即进入普通阅读器、恢复位置；有效登录时后台检查并补缺页。没有本地页则显示“正在准备课件”，第一张可读页面提交后进入阅读，不强迫先去下载管理。没有页面或权限不足就地解释，可重试或登录。反复点按复用任务；退出准备页不丢已保存内容，显式取消只取消当前获取。

部分保存不等于完整下载。目录重新查询，图片按 remoteKey 去重，逐页提交；已保存页复用，只下载缺页。跟看、普通下载共用身份与写入保护，活动跟看占用的课次不能再开启普通下载。回收站中的课件不会因点课表偷偷恢复。

## 实现与检查

TimetableScreen 放在 ui；SchoolApi 读取真实字段；SchedulePolicy 统一周界限、状态、可见性、重叠布局与刷新时效。KeyeViewModel 编排账号缓存、请求合并及预取；LibraryStore 保存带更新时间的 CachedSchedule。批量查询的状态独立，复用学校接口和登录失效处理。

已用真实登录课表核对：11 月 4 日“大数据营销”直播 status=1，PPT 从 20 页增至 21 页；随后课表更新为“回放生成中”。同周回放为 status=6，未开始为 status=2 且标签为空；这些课次的 is_live 均为 1，故该字段不能判断实时状态。研究记录仅保留状态、时间、数量与摘要。

检查覆盖周界限、未知状态、可见性、同日重叠、跨日不串列、刷新时效与时钟回拨；模拟器已核对真实周／日切换、深色及 1.3 倍字号；历史周往返浏览时保存时间不变，确认复用缓存而非每次重查。未认证检查入口保留真实 Cookie，使用已保存课表打开 58 页本机课件并恢复阅读位置；经过 R8 压缩的包也已覆盖安装核对课表和续读。完整直播结束至最终回放、特殊权限限制仍需相应真实样本，不将缺少样本描述为已验证。

依据：[学校课表](https://video.jw.scut.edu.cn/)与[官网课表前端](https://video.jw.scut.edu.cn/static/js/3.7581509b70b2315450f1.js)。本功能只阅读课件，不包含音视频播放，也不依赖自建服务器。
