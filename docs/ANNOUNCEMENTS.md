# 应用公告

公告与更新共用首页弹窗调度，分别获取内容。更新仍从 GitHub Releases 获取；公告来自自建服务器的 HTTPS JSON 文件，无需数据库、登录或管理后台。

## 交互

- 启动并进入课表／课程首页后检查；等待内容检查结束，优先显示更新，其次显示最新的未读有效公告。
- 一次进入应用最多自动显示一个消息；阅读、学校登录、导出等流程不自动弹出。未轮到的消息可在下次启动显示。
- “已阅读”按公告编号与修订号保存于本机，同一修订不再自动弹出。“稍后提醒”、返回和点弹窗外部均延后 24 小时，不标为已读。
- 课表、课程和我的顶部信封打开“消息”，同时显示可用更新和服务器保留的公告。信封和未读条目显示红点；打开条目即标为已读，已读消息仍可查看。新版使用独立的版本号记录已读状态。“刷新”同时检查公告和更新。
- 已到期公告仍在历史中，不自动提醒；未来公告和不匹配当前版本的公告不显示。更新条目打开既有更新面板，返回后继续浏览消息。
- 阅读状态不跨设备同步；卸载／清除数据后重置。公告正文为纯文本，不执行 HTML、脚本或自动打开链接。

## 公告服务地址

当前默认公告地址为 `https://keye.kovra.top/announcements.json`，与网站公告板共用同一份文件。网站部署和证书位置见 [网站说明](../website/README.md)。应用不内置模拟公告；公告列表为空且没有可用更新时，“消息”显示“暂无消息”。更新功能独立获取数据。

如需覆盖默认地址，可通过构建参数或本机 Gradle 配置设置 `keyeAnnouncementsUrl`：

```powershell
.\gradlew.bat :app:assembleDebug -PkeyeAnnouncementsUrl=https://keye.kovra.top/announcements.json
```

正式安装包必须包含实际地址并重新构建。地址只允许 HTTPS、默认 443 端口，不允许凭据、查询参数或片段，不自动跟随重定向。请直接提供返回 HTTP 200 的 JSON 文件地址。将构建属性显式设为空字符串可停用网络获取。

## 文件格式（schemaVersion 1）

可参考 [announcements.example.json](examples/announcements.example.json)。`announcements` 数组为空表示撤下全部公告。

```json
{
  "schemaVersion": 1,
  "announcements": [
    {
      "id": "school-network-20261114",
      "revision": 1,
      "title": "学校平台访问提示",
      "body": "若登录页面提示 HTTP 403，请尝试连接校园网或学校 SSLVPN，并检查代理设置。",
      "publishedAt": "2026-11-14T12:00:00+08:00",
      "expiresAt": null,
      "minVersionCode": 1,
      "maxVersionCode": null
    }
  ]
}
```

- `id`：必填、唯一，1–80 个英文字母、数字、下划线或连字符。同一公告修改后保持编号。
- `revision`：正整数，默认 1。需要已读用户重新收到修改后的内容时递增；小幅错别字修正可保持不变。
- `title` / `body`：必填纯文本，标题最多 100 字符、正文最多 12000 字符；正文可用 `\n` 分段。
- `publishedAt`：必填，带时区的 ISO 8601 时间。`expiresAt`：可选，到此时间停止自动提醒。
- `minVersionCode` / `maxVersionCode`：可选，按 Android 数字版本号筛选，默认从 1 起、不设上限。

服务器保留哪些条目，公告板就展示哪些条目。每份文件最多 50 条、256 KiB；建议只保留近期仍有参考价值的公告。使用原子替换发布文件，避免客户端读到未写完的数据。应用中已打开的公告会允许用户读完。

## 缓存与失败

启动及回到前台时检查缓存；自动获取成功后缓存六小时，失败后十五分钟内不自动重复请求；手动刷新不受此间隔限制。连接、读取各超时十秒。

成功解析整份文件后才替换缓存。网络错误、证书错误、非 200 响应、无效 JSON、未知格式、重复编号或超限内容均保留上次有效内容。后台失败不弹错误；手动查看时显示简短失败提示。阅读与提醒时间保存在本机，不发送学校账号、Cookie 或阅读状态。
