# Keye 0.3.0

## 课表与直接阅读

- 新增“课表”首页，默认显示整周课程，可切换当日时间轴，支持前后周、“今天”和日历定位历史课次。
- 使用学校真实状态显示直播中、未开始、回放生成中和回放；直播课次可直接进入课堂跟看。
- 点开已保存课件立即续读；没有本地页面时按课次获取，第一张页面就绪即可开始阅读。
- 课表长期保存在本机，登录失效仍可浏览已保存周并打开已下载课件；按浏览方向提前准备邻周，减少切周等待。

## 获取与课堂跟看

- 部分保存的课堂课件可重新检查并补全缺页，复用已有图片；取消、失败或中途退出保留已保存内容。
- 普通下载与活动跟看避免重复占用同一课次，补页保留阅读位置、书签、页面移除和文字批注。
- 保留日期范围、多选及课程折叠的批量获取；从课表或课程页可直接进入。

## 界面与构建

- 底部导航调整为“课表 / 课程 / 我的”。课表课程块改善配色与排版，课程卡片更紧凑，导入入口不再遮挡课程名称。
- 整理代码结构，正式安装包启用代码优化、混淆和资源压缩。

## 安装与使用

支持 Android 8.0 及以上，可直接覆盖升级此前正式版，保留本机课件和阅读记录。学校功能需要有效学校登录；离线课件阅读不受登录状态影响。

安装包保持相同正式签名。早期通过开发工具安装的 Debug 版使用不同签名，不能直接覆盖；如遇冲突，请先导出重要资料，确认并处理旧测试版或手机分身中的残留。

课堂跟看用于实时更新课件，不包含音视频播放。下载和导出随应用进程运行，不提供进程退出后的持久后台恢复。
