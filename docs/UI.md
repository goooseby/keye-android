# 界面规范

## 样式

KeyeTheme 定义浅／深色主题、字体和圆角；AppIcons 使用原创 24 单位圆头描边矢量。浅色使用白底、浅蓝灰卡片（#F0F3F8）、浅蓝选中底板（#C3EAFF）和蓝色动作（#00658A）；深色使用蓝灰表面与浅蓝动作。课程封面使用浅蓝、淡紫、浅琥珀和薄荷底色，功能图标按用途着色，文本不跟着随意变色。正文 14–16 sp，顶级标题 21 sp，辅助文字 12 sp。图标操作触摸区至少 48 dp，状态不只依赖颜色。

UiComponents 提供分段导航、搜索、图标底板、空状态、表单标题与设置条目。工具面板只展示可执行功能，不展示标语或占位功能。

## 页面

- 课程：首页最近阅读／全部课程，显示读到的页码；课程内可切换日期顺序。回收站从我的进入。
- 课堂跟看：获取页课次右侧入口，今天快捷查询；观看区顶部连接状态，底部前后页、页码与跟随，第二行总览／批注／保存当页／导出／全屏。回看时显示未看新页数，点击回到最新恢复跟随。无页面时等待，错误保留缓存，背景暂停。
- 阅读：顶部返回、标题、分享、更多；底部总览、页码、书签、工具与全屏。缩略图按需打开，整理动作不常驻。常规锁定竖屏，默认零间距纵向连续阅读，可选横向逐页；单击收放工具，背景仅改变课件周围。
- 阅读工具：按阅读、页面、导出与分享分组，双列图标与文字按钮；首页／末页、下一书签、还原缩放就近可用，查看设置包含局部亮度调整与系统亮度开关。
- 页面总览：自适应缩略图网格，当前页描边、页面／书签／已移除筛选；普通点击定位，选择或长按可批量移除，在已移除中单页或批量恢复。
- 全屏：自动横屏、逐页显示并隐藏系统栏，播放器式控件直接覆盖在课件上，显示退出、书签、缩放复位、前后翻页和进度拖动，不显示普通工具栏或分享管理菜单；闲置三秒后淡出，单击唤回，操作及拖动重置计时；触摸探索时保留控制栏；退出自动竖屏并恢复原常规阅读方式。保留课件比例，不裁切填满屏幕。
- 导出：底部表单，默认文件名与位置，全部／当前／指定范围，导出和导出并分享；分享菜单另提供 PDF 和当前页图片。
- 获取：紧凑日期工具栏、默认折叠的课程分组和 52 dp 起的课次列表，点标题展开，顶部可全部展开／折叠，摘要显示已选数，组内全选，已下载可打开，选择后显示下载栏。
- 下载管理：连续紧凑行、单行标题、状态摘要、3 dp 进度条，取消／重试位于行尾；详细错误点开查看。
- 登录状态：获取页未登录／失效时直接显示登录入口；验证中显示进度，网络问题提示无法验证与重试，不伪装成退出登录。我的账号卡同步显示状态。
- 我的：账号、下载管理、下载参数、保存位置、回收站与应用更新。
- 更新：自动提示简洁列出版本、说明和大小，含下载／稍后／忽略及关闭提醒；详情底部面板集中显示检查、后台进度、重试或直接安装与自动提醒开关。下载可离开面板，安装失败解释原因，签名不符不诱导反复下载。

## 状态与动效

页面位移淡入 230–270 ms，底部栏目使用短距离淡入，分段指示器与文字颜色共用一条 240 ms 位移过渡，无独立阴影和点击光晕；普通工具栏使用淡入与高度过渡，全屏控件仅淡入淡出、不改变页面尺寸，进度插值更新。下载队列固定入队顺序，行进入／退出以同一套位移、淡出和高度过渡管理，不叠加列表 placement 动画；已有行不重复入场。跟随系统动画倍率。

初次读取显示加载状态，不先闪空列表；大文件后台解码，阅读与小缩略图缓存分开。表单处理键盘边距、就地校验与禁用状态；分享取消不报发送成功。导出结果不会强制打断阅读。

## 检查

使用 MainActivity 和真实本地／学校课件验证进度、旋转、缩放、导出内容与分享授权。Debug 的 UiGalleryActivity 用合成内容辅助观察空状态和任务状态，不包含在 Release 包内。

```powershell
adb -s emulator-5554 shell am start -n io.github.goooseby.keye/.UiGalleryActivity --es page acquire
```

视觉覆盖正常屏幕、360 dp 宽度、1.3 倍字号、深色、常规竖屏锁定、全屏自动横屏与返回竖屏、键盘展开。导出覆盖页码范围、同名编号、取消、位置授权和分享面板；不向联系人发送测试文件。
