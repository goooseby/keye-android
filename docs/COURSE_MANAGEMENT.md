# 课程管理设计与实现

本稿基于 2026-11-16 工作区代码检查，第一版于 2026-11-17 实现。下文“当前状态”保留实施前的问题背景；操作、页面、回收站及自动建课规则已接入应用，设备验证记录见文末。

## 当前状态

- `Course` 只有 id、名称、学期和创建时间；学校课程使用 groupId 作为本地课程 id，自建课程使用随机 id。
- 课程首页提供新建，课程详情更多菜单提供编辑；课件支持单份或批量归类、移入回收站及恢复。
- `StudyMaterial.courseId` 是可空的本地归属；`schoolEntry` 保存学校来源，两者可以不同。移动课件后，学校来源仍然保留。
- `LibraryStore` 没有课程删除能力，回收站也只有课件，没有课程状态或课程恢复记录。
- 批量查询完成、首次下载、课堂跟看初始化都会补建学校课程。直接删除课程记录，会导致它再次出现。
- 当前 SQLite 表内保存 JSON，结构版本为 1；课程与课件的批量管理应通过事务统一提交。

## 目标与范围

让用户能够清理空课程、取消课程分组、移除整门课程并恢复，避免课程列表持续膨胀。所有操作作用于本机资料库，不修改学校课表或学校平台上的课程，也不删除已导出到公共目录的文件。

第一版包含：课程详情中的编辑、解散、删除，课程回收站和恢复，以及自动建课规则修正。已有课件批量归类继续复用。合并课程、归档和课程批量操作留到后续，避免第一版同时引入多套状态。

## 操作定义

| 操作 | 课程去向 | 正常课件 | 已在回收站的课件 | 恢复方式 |
| --- | --- | --- | --- | --- |
| 编辑课程 | 保留 | 不变 | 不变 | 再次编辑 |
| 解散课程 | 从列表移除 | 变为未归类，继续可读 | 保持回收站状态，归属也清空 | 不提供长期整组恢复，可重新建课并归类 |
| 删除课程 | 进入课程回收站 | 随课程移入回收站 | 保持原状态 | 恢复课程及本次随课程移除的课件 |
| 删除空课程 | 直接移除分组 | 无 | 若有关联回收站课件，清空其归属 | 重新建课 |

“空课程”指没有正常课件，确认页仍需列出关联的回收站课件数量。此处删除空课程采用解散语义，底层仍保留隐藏记录以抑制自动重建。

不使用含糊的“删除时保留文件”复选框。菜单直接区分“解散课程，保留课件”和“删除课程及课件”。第一版不增加永久清除文件，沿用可恢复的回收站机制。

## 页面与入口

保持“课表 / 课程 / 我的”三个一级入口。

1. 课程 → 全部课程：保留课程列表与“＋”菜单，提供新建课程和导入课件。
2. 课程详情 → 更多：提供编辑、解散和删除，直接管理当前课程。
3. 我的 → 回收站：增加“课件 / 课程”分段，默认课件。课程项显示名称、删除时间和可随课程恢复的课件数。

不设置独立课程管理页，避免与课程详情重复。课程详情已有“选择课件 → 归入课程”可完成内容整理。“未归类”是系统集合，不提供编辑、解散或删除集合的动作。

沿用现有 Material 3、课程色板和底部面板，不为此新增视觉体系；只有删除确认按钮使用危险色。适配深色、360 dp 宽度和 1.3 倍字号。

## 确认与反馈

### 解散

标题：“解散「高等数学」？”

正文：“12 份课件将移到未归类，下载内容、阅读进度、书签和批注都会保留。另有 2 份课件仍留在回收站，恢复后也将位于未归类。以后获取这门课的内容默认放入未归类。”

按钮：“取消 / 解散并保留课件”。成功后返回全部课程，提示“课程已解散，12 份课件已移到未归类”。第一版不提供撤销按钮，避免后续课件移动与撤销相互覆盖。

### 删除

标题：“删除「高等数学」及课件？”

正文：“课程和其中 12 份课件将移入回收站，可在‘我的 → 回收站 → 课程’恢复。原已在回收站的 2 份课件不会随课程自动恢复。”

按钮：“取消 / 移入回收站”。成功后返回全部课程，提示“课程及 12 份课件已移入回收站”。不逐份弹出提示。

### 空课程

菜单显示“删除空课程”，确认说明只移除课程分组；如有回收站关联课件，明确说明恢复后进入未归类。无正常课件时不同时显示两个结果相同的移除动作。

### 提交状态

确认面板打开时显示当前数量，提交时重新读取并校验。数量发生变化则更新说明，要求按新数量重新确认。提交期间禁用重复点击；数据库成功后再关闭面板和返回，失败保留面板并显示错误。

## 学校课程与后续获取

课程管理必须同时修正自动建课，否则删除后重新出现的问题仍然存在。

- 仅查询学校课次不再创建本地课程；首次实际保存课件时才创建。已有空课程保留，用户可以自行清理，不做自动批量删除。
- 正常学校课程：新课件继续进入该课程，用户编辑过的名称、学期不被学校数据覆盖。
- 已解散的学校课程：保留同一 id 的隐藏记录，后续新课件进入未归类，不自动重建。首次后续获取时通过轻量提示说明归属，并提供“归入课程”入口；来源信息不变。
- 已删除的学校课程：打开已删除课件时提示先恢复；获取其他课次时，先提供“恢复课程 / 保存到未归类 / 取消”。恢复课程会按回收站规则恢复内容，确认文案必须显示数量。批量获取时先汇总这些课程，一次确定归属再开始排队。
- 将某份课件归入其他课程后，补页仍保持该份课件当前归属，不用学校 groupId 覆盖。管理操作只处理执行时仍属于该本地课程的课件。
- 自建同名课程不视为恢复；归属和来源均按 id 判断，不按名称猜测。

## 回收站恢复规则

删除课程时生成一次操作编号，只给本次从正常状态变为已删除的课件记录该编号。此前单独删除的课件不带该编号。

“恢复课程及课件”恢复课程，以及仍处于本次删除批次中的课件。此前已在回收站的内容继续保留；已经单独恢复或移动的内容不再被整组恢复修改。单份恢复先清除其批次标记：课程仍被删除时，该课件进入未归类；课程已正常时，保留原归属。

课件回收站可以展示全部已删除课件；随课程删除的课件附“随「课程名」移除”说明，并提供跳转所属课程回收站项的入口。课程分段不复制课件数据。

## 数据与实现方案

建议为现有 JSON 增加兼容字段，第一版不改 SQL 表结构：

- `Course.lifecycle`：`active / dissolved / trashed`，旧数据默认 active。dissolved 仅用于隐藏记录，不出现在课程回收站。
- `Course.removedAt`、`Course.removalBatchId`：删除时间与当前删除操作编号。
- `StudyMaterial.courseRemovalBatchId`：可空，只标记随课程删除的成员；手动恢复或重新归类时清空。

所有课程显示、搜索、导入目标和归类目标只接受 active 课程；管理逻辑仍可读取完整课程记录。解散时清空所有关联课件的 courseId，包括已删除课件，保留课件自身 deleted 状态；删除时保留关联，以支持整组恢复。隐藏记录不会参与课程计数。

`LibraryStore` 增加事务方法统一保存课程和课件变更；`KeyeViewModel` 增加解散、删除、恢复及后续获取归属决策。统一封装课程状态与新课件归属解析，替换查询、下载、跟看中分散的自动建课逻辑。

课程变更沿用 materialMutex，与逐页保存互斥，并在同一事务中完成。任务入队、重试与提交都要重新校验目标课程状态，避免导入使用失效的 courseId。锁内不执行网络、文件复制或图片解码。课程操作不改变 readAt、页码、内容 revision 或导出有效性。

若该课程有关联的等待中或运行中下载、导入、补全，或尚未结束的跟看会话，第一版暂不允许解散或删除。面板说明“该课程还有进行中的任务，请完成或取消后重试”，提供下载管理入口；跟看提供返回会话的入口。识别关联时同时检查现有课件归属、下载课次来源和导入目标，不只匹配 task.materialId。检查与入队受同一同步机制保护；仅前端禁用按钮不足以防止竞态。

已冻结快照的导出可以继续完成，其结果写回必须读取最新课件，只更新导出字段，不能覆盖删除状态。课程删除不清理媒体文件和已有公共导出。

课程详情操作成功后清除当前课程路由；若其他入口持有已失效 id，返回课程列表并提示，不能落入当前“找不到课程就显示未归类”的回退逻辑。

## 验收

1. 自建空课程、学校空课程均能移除；重启及再次查询学校课次后不重新出现。
2. 解散包含正常及回收站课件的课程，所有归属清空，deleted 状态分别保留，文件、进度、批注、书签不变。
3. 删除课程后首页、最近阅读、搜索和归类目标均不显示该课程的已删除内容；课表仍保留学校课程。
4. 恢复课程仅自动恢复本次随课程删除的课件；此前已删、单独恢复或移走的课件不受影响。
5. 解散后再次下载、跟看新课次进入未归类；删除后获取新课次先处理归属，不静默重建或恢复旧内容。
6. 已移入其他课程的学校课件补页后归属不变；批量查询不再产生空课程。
7. 活动任务阻止课程移除；任务完成或取消后可执行；历史失败任务重试时重新解析归属。
8. 事务失败不产生部分变更，重复点击只提交一次，重启保留课程状态；旧 JSON 缺省字段正常读取。
9. 导出与删除并发不会恢复旧状态；已导出文件仍可访问。
10. 未归类无课程级删除入口；课程消失后无悬空详情页；深色、小屏和大字号下确认信息与操作完整可用。

## 建议落地顺序

先完成状态字段、事务与自动建课规则，再接入单门课程操作和课程回收站。优先验证解散、删除批次恢复、后续获取归属及任务并发规则，再做设备界面验收。

## 实现与检查入口

- 入口：课程详情 → 更多；我的 → 回收站 → 课程。
- `domain/CourseManagement.kt` 统一解散、删除、恢复和学校来源归属规则；`LibraryStore.putCourseChange` 通过事务保存课程及成员变更。
- `KeyeViewModel` 发布正常课程与完整课程记录两套视图，下载、导入和跟看检查课程状态，活动任务阻止移除。`UiState.busyCourseIds` 使任务结束后的可操作状态及时更新。
- `CourseActions.kt` 提供确认面板、课程回收站与后续获取归属选择。整门操作失败保留面板；课程失效时退出详情。
- 字段均采用兼容的 JSON 可选字段，SQLite 表结构版本保持 1，不清除旧资料。解散和删除不进行文件清理；已导出文件不受影响。
