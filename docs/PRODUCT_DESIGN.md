# 课页产品与交互设计

## 产品定位与取舍

课页是一款用于获取、离线阅读和回看课程课件的 Android 应用。核心流程是找到课程、打开课件、接着阅读；页面整理、下载管理和导出服务于这条流程。

界面优先保证内容清楚、操作容易发现、默认行为合理。常用动作就近放置，低频工具按需展开，用完回到原阅读位置。借鉴阅读器与笔记应用的内容布局、工具面板和默认保存行为，不照搬其完整功能集合。

学校课件图片、本地 PDF 和图片均可阅读。这里的“看课程 PPT”指课程内容用途，并不表示支持直接解析 PPTX、幻灯片动画或演讲者备注。图片没有文字层时，不展示可用的全文搜索或文字选择入口。

## 导航与课程

一级入口为“课表”“课程”“我的”，默认打开课表。课表默认以整周时间格展示，可点击日期或切换到当日课程，支持日历定位历史日期；点课次即阅读或准备课件。学校确认直播时直接跟看。课程首页保留最近阅读和全部课程，支持搜索；最近阅读按实际阅读时间排序，重命名、导出、书签和页面移除不改变阅读顺序。课程内按课次日期排列，可切换正序。

批量获取从课表顶栏或课程首页的“获取课件”进入，保留集中选择与下载能力，不占用独立底部栏目。两条找课路径共享本地课件和阅读进度。课表先用本机内容显示、按浏览方向准备少量邻周，已看过的课表长期保存；登录失效显示提示，仍可按课表打开已下载内容。加载、真实状态与直接阅读的完整规则见 [课表与直接阅读](TIMETABLE.md)。

课件列表显示名称、日期、页数与上次位置。打开后自动续读，不要求先整理、筛选或导出。没有阅读记录时显示最近加入的课件，不放空的“继续阅读”占位容器。

批量获取页负责学校登录、日期查询、课次选择与下载。快捷日期提供今天、近两周和本学期。本学期从最近一个 3 月 1 日或 9 月 1 日附近的周一开始，到今天结束；始终选择已到来的学期起点，开始和结束日期可手动微调，一次查询上限 220 天。查询结果默认按课程全部折叠，点击课程标题展开／收起课次，顶部分组工具可全部展开／折叠；折叠不清除选择，课程摘要保留已选数量，全选框区分未选、部分选择和全选。重新查询得到新结果时恢复全部折叠。下载管理从获取顶栏和我的进入；任务是获取内容的过程状态，不作为阅读的前置步骤。已下载课件可直接打开，退出账号不删除本地内容。

学校连接状态区分未登录、验证中、已连接、暂时无法验证与登录已失效。启动／回到前台、进入获取或我的时检查，前台期间定期复核；查询和下载返回明确认证失败时立即要求重新登录。获取页未登录或失效时直接显示登录入口；我的显示一致状态。断网、超时、服务异常和图片链接错误不能直接判为退出登录，保留凭据并提供重试。登录页面使用实际平台请求确认成功，不能只凭 Cookie 的存在显示已连接。

登录信息保留到平台自身到期或用户主动退出；自动检查、打开登录页和网络失败都不清除 Cookie，不主动缩短学校会话寿命。重新登录可复用学校单点登录。

本地导入、重命名、归类、课程批量导出与回收站置于明确的添加或更多入口。学校登录独立全屏。本机已有内容可离线阅读和导出。

## 课堂跟看

课堂跟看用于阅读持续增加的课程课件，不包含音视频。课表和课程首页依据学校新鲜 status=1 显示直播入口，批量获取也可进入；课表时间和 is_live 类型标记不能单独证明正在直播。缓存状态过期时不展示实时确定性提示，既有会话仍可继续。已保存的学校课件也可从阅读器更多菜单重新连接，跟看不另占底部栏目。状态定义、缓存与验证边界见 [课表与直接阅读](TIMETABLE.md)。

进入后复用同一课次的本地课件，新增页边获取边保存到所属课程。退出、暂停或结束只停止同步，已经保存的页面继续可读；它们不代表老师之后不会再增加页面。获取页显示已保存页数，以及已知缺页时的“待补全”；已有课件仍可选中“检查并补全”，只下载缺少的页面。离开跟看后可转为一次性补全，不能让同一课次的两个写入流程并行。取消或失败保留逐页保存的结果，重试从缺页继续，不覆盖批注、书签、移除设置和阅读位置。没有页面时显示等待，不把“老师还没上传”当作异常；首次进入先获取最新页和最近几页，随后补齐更早页面。每批最多三页，并在批次间重新检查目录，避免长时间补历史页错过新内容；初始补页期间始终优先展示最新内容，不从第一页逐张跳到最后。历史页按目录顺序插入时，同步迁移书签、移除状态、批注与阅读位置；页面身份使用稳定文件来源，回看内容不因前方补页而改变。默认约每三秒检查一次，可改为五秒或十秒。请求串行，普通列表刷新和图片下载不重叠；网络异常按三、六、十二、二十四、三十秒逐步降低频率，并尊重平台限流的等待提示。离开跟看界面、锁屏或切到后台即暂停，不靠后台常驻维持轮询。进程结束不自动恢复网络请求，已保存内容仍在课程中。

跟随和同步是两个独立状态。默认跟随最新已保存页；手动翻页、拖动页码、放大查看、打开总览或编辑批注后进入回看，新页继续保存但不强制跳转。页面上保留“回到最新”及未查看的新页数量，用户主动恢复跟随。即使手动回到末页，也不擅自恢复跟随。可以单独暂停同步，或结束跟看并保留全部已获取内容。

纵向握持时顶部显示课次和连接／保存状态，底部提供前后翻页、页码、跟随开关，以及总览、批注、保存当页、PDF 导出和全屏。全屏自动横屏，只保留覆盖在课件上的观看控件；回看时保留“回到最新”，不把管理菜单搬到全屏里。旋转和面板开合不能把回看悄悄变成跟随。

文字批注按原始页码关联，是页面下的文字记录，不在原课件上覆盖绘制。未保存编辑退出时确认放弃；保存后可从普通阅读器继续编辑。保存当页输出图片及其批注，Android 10 起默认放在“图片 / Keye”，旧系统用文件选择器；PDF 表单可选择是否包含批注。批注作为页尾附录输出，保留原图。导出打开时冻结已有页和批注，本次输出不会随后续增页不断变大，也不会丢掉导出期间继续获取的新页。

对新课件用稳定的页面地址标识去重，忽略已知临时鉴权参数但保留页码等业务参数；同一个地址的授权变化不重复下载，平台短暂返回空列表、缩小列表或重排时不删除／重排已保存页。旧版本下载没有地址标识时，通过原始文件内容匹配补充标识，不凭位置猜测，不覆盖批注和阅读记录。已有移除页设置继续有效。

同一时刻只有一个跟看会话，切换课次前确认保留并切换；同课次不会和普通下载同时写入。登录失效停止联网并显示登录入口，缓存、批注和导出仍可用；重新登录后可继续补页。回收站中的课件需先恢复，不自动复活用户删除的内容。

## 常规阅读与屏幕方向

常规应用界面固定竖屏，包括课程、获取、下载管理、我的、学校登录和普通阅读。转动手机不把这些页面切成未经设计的横屏界面。横屏仅用于用户主动进入的全屏阅读。

阅读器独立于应用底部导航。顶部为返回、课件标题、分享和更多；底部为页面总览、页码、书签、阅读工具与全屏。缩略图网格按需打开，不用常驻长条挤占内容。页面移除放在工具和总览中，不要求用户在日常阅读时维护保留状态。

| 阅读形态 | 方向与排版 | 操作 |
| --- | --- | --- |
| 连续阅读（默认） | 竖屏，课件按宽度保持原比例，一页紧邻一页，不额外插入大间距 | 上下滑动连续浏览 |
| 逐页阅读（可选） | 竖屏，单页完整适合可用空间 | 左右滑动翻页 |
| 全屏阅读 | 自动横屏，单页适合显示，原比例、黑色留边 | 左右翻页，点击收放悬浮阅读控件 |

“查看设置”可切换常规阅读方式，并记住用户的主动选择。第一次使用采用纵向连续阅读。进入全屏不改写这个偏好。

连续阅读把所有页面视为一份纵向文档，双击／双指缩放统一改变整份文档宽度和页面高度，页面仍紧邻，可在放大状态下继续纵向滚动、横向平移，不给每页单独的缩放框。逐页和全屏采用独立的单页缩放。缩放仅作用于课件区域，工具栏和其他页面不变。单击等待双击判定后再切换工具栏，避免双击同时引发闪烁。PDF 与图片读取原件，在放大时提高渲染尺寸，不能把列表缩略图当作正式阅读图像。

连续阅读保存原始页码及页内相对偏移。切换方式保持当前原始页；重新打开和进程重建恢复位置。到达末页不等同于已学会或已整理。

## 全屏的进入、退出与恢复

点击全屏后自动横屏、隐藏系统栏，并从当前页进入逐页显示，不要求用户手动旋转手机或打开系统自动旋转。支持两个横向握持方向。

全屏是独立的观看状态，轻触页面仅切换覆盖在课件上的播放器式控件，不呼出普通阅读工具栏、分享、页面管理或整理菜单。上方为退出、标题、保存当页图片、页书签和还原缩放，下方为上一页、进度滑杆与下一页；控件通过渐变遮罩保证可读性，淡入淡出不改变课件可用空间。首末页禁用对应方向，进度按保留页面定位，同时区分原始页码与保留页位置。

控件闲置三秒后收起；拖动进度时保持可见，松手后定位并重新计时，每次操作都会延长显示。触摸探索辅助功能开启时不自动隐藏。双击缩放、双指缩放与拖动继续可用。全屏期间保持亮屏，退出后恢复常规阅读亮屏偏好。课件不拉伸、不裁切以填满屏幕，屏幕比例不同造成的黑边予以保留。

退出全屏自动回到竖屏，恢复进入前的连续／逐页偏好。仍在原页时恢复原连续滚动位置；全屏中翻到其他页时回到对应页。全屏状态、页码与待恢复的定位信息一起保存，方向变化时不先跳到别的页再跳回来。

系统返回按层级退出：输入与面板 → 全屏 → 课件列表。普通阅读返回列表后保留列表位置。常规阅读保持亮屏由用户主动开启，离开阅读器立即解除。

普通阅读工具面板按阅读、页面、导出与分享分组，提供查看设置、还原缩放、首页、末页、下一书签、页面总览、移除当页、课件信息及导出分享。下一书签循环定位其他保留页，没有可跳转书签时禁用。查看设置提供背景、阅读方式、亮屏与阅读器独立亮度；亮度默认跟随系统，手动调整只影响当前阅读窗口，离开后恢复，不要求修改系统设置权限。

## 页面总览、移除与恢复

总览使用自适应缩略图网格，当前页描边，标记书签。按“页面”“书签”“已移除”筛选；长课件只加载可见范围所需的预览。

普通点按缩略图定位并回到阅读。点击“选择”或长按进入多选，支持全选和批量移除；阅读更多菜单也提供“移除当前页”。

页面移除是一项持久但可恢复的课件修改：

- 确认后从连续阅读、逐页阅读与默认导出中跳过所选页。
- 原件保留，完成提示可以撤销，也可在总览的“已移除”中单页或批量恢复。
- 至少保留一页，不能把课件移成空文档；越界选择在数据层也被拒绝。
- 移除当前页后定位到后面的最近保留页，没有后续页时回到前一保留页。移除其他页时保持当前内容。
- 恢复不修改页面顺序和书签；被移除页的书签随页保留，恢复后重新可见。

原始页码始终作为页面身份。总览、阅读页码和指定导出范围沿用原始编号，移除后允许页码跳号，不把原第十页悄悄改名为第八页。阅读标题和导出表单显示保留页数；输入已移除页的跳转页码时提示先在总览恢复。

移除整份课件与移除页面是两个动作：整份课件移至“我的”的回收站，页面通过课件总览恢复。

## 导出、保存与分享

阅读器更多菜单打开导出 PDF 底部表单，默认填写课件名称、日期和保存位置，支持全部、当前页及指定范围。字段留在手机面板内，键盘打开后仍可滚动完成操作。

“全部”输出所有保留页。指定范围使用原始页码，支持“1,3-5,8”和中文逗号，去重并按原顺序输出，自动跳过已移除页。合并多份课件时按选定顺序累计原始页码。自定义范围只影响本次输出，不改变课件的持久页面选择；范围全为空、倒序、越界或没有可输出页时就地解释并禁止执行。

| 动作 | 文件与后续行为 |
| --- | --- |
| 导出 | 永久保存 PDF，提示实际位置并提供打开、分享，留在阅读器 |
| 分享 PDF | 生成临时 PDF 后打开系统分享面板，不要求先选永久目录 |
| 导出并分享 | 永久保存后分享同一份结果；取消分享不删除已保存文件 |
| 分享当前页图片 | 使用当前原始页面生成 PNG 后交给系统分享 |

Android 10 起默认保存到“下载 / Keye”；可授权其他文件夹并记住位置。Android 8–9 第一次保存需选择目录，此后复用。文件名过滤非法字符，同名自动编号，默认不覆盖。授权失效或存储不足要说明原因，不静默保存到难以找到的私有位置。

仅当完整输出未移除任何页面的单份 PDF 时优先复制原件，保留文字和矢量。图片课件、部分页及合并输出使用图片型 PDF，并如实说明清晰度与文字层限制。正式输出不使用列表预览图。

分享由 Android 系统提供目标列表，不写死 QQ、微信等入口；只有已安装且支持格式的应用才可能出现。不把打开分享面板或选择应用当成对方收到，不显示无法证实的“发送成功”。用户离开原页面或切到后台时不突然弹出分享，由完成提示主动继续。

长操作显示进度、允许取消且不强制跳转。永久输出与临时分享缓存分别管理；分享后不立即删除接收方仍可能读取的缓存。下载和输出当前随应用进程运行，进程退出后的持久后台恢复需要独立能力支持。

## 下载队列与动效

一次选择多个课次时，整批建立等待记录并一次发布，再按并发上限启动。保存不可变的入队时间与批内顺序；下载进度和完成时间不能改变队列位置，重复发布同一批也不能产生重复行。

“全部”保留完成记录，“进行中”在完成或取消后移出，“未完成”保留失败和取消结果。正在查看历史记录时不强制滚回顶部。

队列变化以行的进入／退出和占位高度变化表达：新行轻滑入，其他内容随占位展开自然下移；进行中的行完成后滑出，再随占位收拢让邻行上移。高度只由一套过渡管理，不叠加另一套列表位移动画反复追赶。进度变化保持行高与位置稳定，离场过渡结束后才移除展示记录。页面本身已在进入时，不再给全部已有行叠一轮入场动画。

所有分段标签使用统一控件。选中底板的位置和文字颜色由同一条 240 ms 过渡驱动，不另设先出现的阴影或点击光晕；字体粗细保持稳定，避免文字跳动。快速连续点按从当前动画位置继续，不能先跳到终点再播放位移。键盘焦点单独提供清楚的焦点描边。

动效必须解释变化，不拖延操作。跟随系统动画倍率，关闭动画后直接呈现正确终态。优先保持可读性、触摸区和状态清楚，不以过度回弹制造活泼感。

## 应用更新

更新从 GitHub 正式 Releases 获取，启动时静默检查，自动请求按本地日期每天最多一次，失败不打断使用，也不当天连续重试。手动检查位于“我的 → 应用更新”，随时可用。提醒等到普通应用页面显示，不打断阅读、学校登录或导出；支持稍后、忽略此版本和关闭自动检查与提醒。

只有用户点击下载才获取安装包，事先显示版本、发布说明、大小和移动数据提示。系统负责后台下载，面板可关闭，重启后恢复任务状态。已经下载并校验的包直接安装，取消安装或未授权不会造成重复下载。包损坏允许重下，包名、签名或系统不兼容则明确阻止。

普通前台页面下载完成后继续系统安装确认；后台完成发通知，点击后安装，不强拉后台界面。权限只在用到时解释并申请；拒绝通知仍可在面板继续安装。更新是同签名覆盖安装，不清除课件、阅读进度或学校登录，也不把唤起系统安装器当作成功。

[更新与发布](UPDATES.md)定义版本协议、每日限制、安装包校验、后台行为和正式签名流程。

## 我的

我的使用紧凑的账号卡片和三组设置：下载管理与参数、导出位置与回收站、版本更新与 GitHub 仓库。账号直接显示连接状态，退出与重新验证保留明确触摸区；资料保存在本机及卸载前导出的说明合并为一行。GitHub 行打开公开仓库，说明代码公开、欢迎探索和改进。标准手机与默认字号在一屏内显示全部入口；小屏、超大字号和异常提示仍允许滚动，不能以截断或缩小触摸区强行凑满一屏。

## 视觉与能力边界

浅色使用白底、浅蓝灰内容底板和清亮蓝色选中态，深色使用蓝灰层级与浅蓝重点，跟随系统。课程封面及图标以蓝、紫、绿和琥珀作少量功能区分，正文保持深中性色，大面积背景避免高饱和彩色；图标使用统一矢量语言，文字与图标共同解释低频动作。正文 14–16 sp，辅助文字 12 sp；图标触摸区至少 48 dp，大字号时让布局增长，不能压缩成竖排按钮。

没有标语、空按钮或尚不能完成的工具入口。笔迹批注、OCR、全文搜索、自动播放、云同步与原生 PPTX 解析需有完整数据和业务支持后再引入。

加载、空结果和失败分别表达。网络断开不影响已保存课件；失败有具体原因与继续路径，操作取消不冒充成功。

## 验收场景

1. 一次加入九个下载任务，进度交替更新、部分完成或取消：相对队列位置稳定，无重复行，进入和退出不反复跳动。
2. 快速切换课程、任务和阅读设置中的分段标签：底板、颜色与终态同步，无先到的阴影。
3. 常规页面转动手机仍竖屏；默认阅读紧邻纵向滚动，可主动切换逐页并记住选择。
4. 从连续阅读中间页进入全屏：自动横屏，当前页不变；退出自动竖屏，恢复原阅读方式和相应位置。
5. 单页和总览批量移除、撤销与恢复：阅读和默认 PDF 一致跳过移除页，原始页码不混淆，最后一页不能移除。
6. 指定范围跨越已移除页或跨多份课件，结果页数及顺序正确；非法或空范围不能生成空 PDF。
7. 分享取消、目录授权失效、进程重建、深色、小屏、大字号与键盘展开有明确且可继续的状态。
